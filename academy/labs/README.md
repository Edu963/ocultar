# 🧪 Hands-on Labs

The best way to learn OCULTAR is by doing. These labs will guide you through common technical scenarios.

## 🗂️ Lab Modules

### Lab 1: Local Deployment *(coming soon)*
Start the full stack using Docker and verify the health of each component.

### Lab 2: Customizing PII Rules *(coming soon)*
Add a custom regex rule to the registry and verify it in the dashboard.

### Lab 3: Auditing the Vault *(coming soon)*
Use the DuckDB CLI to inspect the encrypted vault and understand the token mapping.

### Lab 4: The Base64 Challenge *(coming soon)*
Craft a payload that attempts to bypass the filter using nested encoding and see how Tier 0.1 stops it.

---

## 🛠️ Lab Environment
All labs can be performed on a standard developer machine with:
- Docker Desktop
- Go 1.22+
- Python 3.9+
- DuckDB CLI
